## 프로젝트 한 줄 소개

> **"C를 처음 배우는 중학생을 위한 학습 플랫폼 — ① 메모리·변수 시각화 ② 친절한 한국어 오류 메시지 두 가지를 차별점으로 잡았다."**

- 주제 출처: 정보영재원에서 주어진 주제 위에서, 타겟·차별화 방향은 본인이 직접 결정.
- 기술 스택: React 19, Vite 8, JavaScript(ESM), Judge0 채점 엔진, Docker
- 두 가지 차별점:
  - ① **메모리·변수 시각화** — 변수가 메모리에 어떻게 들어가는지 보여주는 학습 방향 (problems.js 의 문제 선별 기준)
  - ② **친절한 한국어 오류 메시지** — Judge0이 돌려준 영문 메시지를 한국어로 의역 (`friendlyError`)
- 보조 기능: 마스코트 "닉스"(게임 좋아하는 학생 흥미유발), 리더보드(랭킹·게임 요소), 다크/라이트 테마, 한/영 다국어, 오프라인 fallback(cValidator.js).
